# Frontend Documentation Structure

Replicate and adapt the Markdown documentation structure used in the Birdwatching AI API into the Birdwatching AI UI.

The frontend documentation should mirror:
- root `README.md`
- root `CONTEXT.md`
- root `AGENTS.md`
- focused docs under `docs/`
- AI-first guidance for Codex, Copilot, Cursor, and future developers
- development prompt history under `docs/development_prompts/`

Adapt content for:
- React 18
- Vite
- chat UI components
- `useChat` state orchestration
- backend API integration
- localStorage conversation continuity
- Railway deployment
- frontend environment variables

Constraints:
- modify only the frontend repository
- treat the backend repository as read-only reference material
- do not invent backend APIs
- document assumptions or future TODOs when behavior is unclear
